# MegaDownloader

A Windows Forms下载管理器, 支持 Mega.nz 及多种链接加密/解密。

## 功能

- Mega.nz 文件下载
- DLC / ELC 链接加密容器支持
- 多文件并发下载
- 速度限制
- 流媒体服务器 (内置HTTP服务器)
- 隐写术 (Steganography) 链接隐藏
- 剪贴板监控自动抓取链接
- 电影元数据 (IMDB / Filmaffinity / Allocine)
- 多语言支持 (英语/西班牙语/法语/德语/中文等)

## 技术栈

- .NET 10 (Windows Forms)
- 反编译自原 MegaDownloader v1.7 (VB.NET)

## 构建

```bash
dotnet build
```
